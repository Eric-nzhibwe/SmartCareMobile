# Assets

Place the following image files in this folder before building:

| File                  | Size        | Purpose                                      |
|-----------------------|-------------|----------------------------------------------|
| `icon.png`            | 1024×1024   | App icon (iOS + Android)                     |
| `adaptive-icon.png`   | 1024×1024   | Android adaptive icon foreground layer       |
| `splash.png`          | 1284×2778   | Splash/loading screen (portrait)             |
| `favicon.png`         | 48×48       | Web favicon                                  |

## Tips
- All images must be PNG with a transparent background (except splash, which has #0f4c81 blue bg).
- The adaptive icon foreground should have generous padding (≥15%) around the logo.
- You can use https://icon.kitchen or https://easyappicon.com to generate all sizes at once
  from a single source image.
